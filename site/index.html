Condition-blind joke detection

The coworker never asks for a joke. Before the chat, participants are instructed to introduce the prepared joke at a natural moment. Every untreated message is checked by the same condition-blind multilingual detector.

Contextual AI reaction controls

DeepSeek generates three matched, context-aware candidate reactions in the participant’s language. The server displays only the assigned candidate. The wording below is used only as a validated fallback if generation fails.
